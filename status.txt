------------------------------------------------------------------------------
WHAT THIS PROJECT IS
------------------------------------------------------------------------------

Dormant-spur pruning in Isaac Sim on the OSU HPC, using Jose's measured Isaac
stack (not NVIDIA 5.x tutorials).

One env, one reward, four observations, five seeds (20 run IDs):

  A  flow 8×8
  B  two real VL53L8CX ToF (8×8)
  C  metric student (8×8 causal table; 256×256 is a second table)
  D  inverse-variance fuse(ToF0 + ToF1 + C) — same width as C, different content

Robot: UR5e + mock-pruner from lukestroh/branch_detection_system (not ag-robot).
v1 does not spawn the hardware linear slider. IK is absolute 7-D EE pose.
DA2-ft proposes a target once per episode, never inside the PPO loop.
Trees are finite UsdGeom.Cylinder (Blender's primitive), not capsules.

Pinned stack that actually renders here:

  SIF     Humanoid_Lite/container/bhl.sif
          sha256 d427d9c3…9bcac29
  venv    Humanoid_Lite/venv-isaac60
  Isaac   Sim 6.0.0.1 + Lab 3.0.0b2, Python 3.12
  launch  BHL_STACK=v60 + bhl_exec from bhl-robustness-ladder/slurm/_env.sh

Isaac Sim 5.1 RTX segfaults in omni.usd.create_hydra_engine on this cluster.
V100 / dgx2-* have no RT cores. Do not run Isaac RTX there.

HOLDBACKS THAT WILL SHOW UP NEXT
------------------------------------------------------------------------------

  - GRES limit: pruning smokes will queue behind height-probe / ood-advanced /
    marl-train. Expected. Do not scancel those.
  - Env smoke may segfault or hang Kit again (same squashfuse class as
    21079145). If JSON exists with "ok": false and a traceback, that is
    progress; fix the construct path. If JSON is missing, Kit died before
    flush — treat as infrastructure, not a physics result.
  - AppLauncher vs SimulationApp: cube Gate 0 used SimulationApp and passed;
    env smoke uses AppLauncher (needed for DirectRLEnv). That difference is
    a likely failure mode.
  - If observation_space comes back 128 or A=B=C, that is the BHL
    "cameras mounted, never read" trap. Fail the job. Do not grep logs.
  - Scripted ToF returns EEF-frame deltas; the env IK is absolute 7-D.
    baselines.sbatch composes them. If that compose is wrong, the arm will
    hold or dive — check EEF motion in the JSON, not just "step returned."
  - CuRobo import will probably be None on v60. Baseline job should still
    pass on scripted ToF + contact, and record curobo_oracle false until
    the wheel exists.
  - Training 20 PPO runs is days of RTX. Do not start them to "complete the
    phase" while baselines are missing.
  - Held-out trees in artifacts/ are not rollouts. Spawning 00042 in Isaac
    without a policy/baseline log is not an eval result.
  - Installing pybullet into depth-env or v60 without a pin will drift the
    stack. If sim2sim is needed, isolate it.
  - Wrist RGB at 8×8 is 192 numbers vs depth 64. If RGB "wins," separate
    colour from width before claiming a perception result.
